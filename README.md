# Presentación Dimak

Repositorio de trabajo para la presentación ejecutiva del proyecto Dimak.

## Archivos de la presentación

- `index.html`: presentación principal.
- `css/style.css`: estilos visuales.
- `js/app.js`: navegación e interacciones.

## Objetivo

Mantener una presentación que pueda revisarse y mejorarse desde PC y móvil, conservando el enfoque de complementar los sistemas y capacidades existentes de Dimak.

## Base inicial

La versión de partida es la presentación anterior recuperada y reconstruida desde su HTML original, separando sus estilos y JavaScript. Los recursos que estaban incrustados en el HTML permanecen dentro del documento principal.

2. Revisar que rutas, navegación y recursos funcionen.
